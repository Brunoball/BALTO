UTILIDADES
Ver qué archivos correría un módulo, sin ejecutarlos:
node tests/ejecutar.cjs movimientos --list

Comprobar que cada test tiene un único módulo dueño:
node tests/ejecutar.cjs verificar

Limpieza manual de datos PW-* si una corrida se cortó (Ctrl+C, cierre de terminal, crash):
node tests/cleanup-now.mjs




NOTAS:
- Todos los comandos se ejecutan desde la carpeta frontend de BALTO_SERVICIOS.
- GLOBAL cubre login, rutas/navegación, seguridad/hardening y chequeos globales existentes.
- La auditoría interna (global/auditoria_solo_completo) NO corre en GLOBAL; sólo en COMPLETO.
- Cada módulo corre sus tests existentes, navegación de sus pantallas e integraciones directas seleccionadas.
- No se ejecutan los otros módulos enteros; no es garantía de cubrir funciones aún sin tests.
- Ejecutar pruebas con escritura únicamente sobre un tenant E2E aislado, NUNCA datos reales.
